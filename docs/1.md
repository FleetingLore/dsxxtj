## 1.1

设 $A_i\ (i \in I)$, $B$ 是 $X$ 的子集, 证明:

### a

$\left(\bigcup_{i \in I} A_i\right) \cap B = \bigcup_{i \in I} (A_i \cap B)$

### b

$\left(\bigcap_{i \in I} A_i\right) \cap B = \bigcap_{i \in I} (A_i \cup B)$

### c

$\overline{\left(\bigcup_{i \in I} A_i\right)} \cap B = \bigcap_{i \in I} \overline{A}_i$

### d

$\overline{\left(\bigcap_{i \in I} A_i\right)} \cap B = \bigcup_{i \in I} \overline{A}_is$

## 1.2

设 X 是任意一集合, $2^X$ 是它的所有子集组成的集合. 证明在集合 $2^X$ 上的对称差运算 $\Delta$ 

$$A \Delta B = (A \cap B) \cup \overline{A} \cap B$$

具有以下性质:

### a

$A \Delta B = B \Delta A$

### b

$(A \Delta B) \Delta C = A \Delta (B \Delta C)$

### c

$A \Delta \varnothing = A$

### d

对于 $X$ 的任意一子集 $A$, 存在 $X$ 的子集 $B$ 使得 $A \Delta B = \varnothing$

### e

$(A \Delta B) \cap C = (A \cap B) \Delta (B \cap C)$

### f

$A \Delta B = (A \cup B) \setminus (A \cap B)$

### g

$A \Delta B = (A \setminus B) \cup (B \setminus A)$

## 1.3

对于有限集 $A_1$, $\cdots$, $A_n$, 证明:

$$
\begin{align}
\left|\bigcup_{i=1}^n A_i\right| &=
&\sum_{i=1}^n \left|A_i\right| - \sum_{1 \le i < j \le n} \left|A_i \cap A_j\right| + \cdots \\ 
&+&(-1)^{k-1} \sum_{1 \le i_1 < \cdots < i_k \le n} \left|A_{i_1} \cap \cdots \cap A_{i_k}\right| + \cdots \\
&+& (-1)^{n-1} \left|A_1 \cap \cdots \cap A_n\right|
\end{align}
$$

## 1.4

$$\varphi(n) = n \left(1 - \frac{1}{p_1}\right)\left(1 - \frac{1}{p_2}\right) \cdots \left(1 - \frac{1}{p_r}\right)$$

其中 $p_1$, $p_2$, $\cdots$, $p_r$ 是 $n$ 的所有不同的素因子, $\varphi (n)$ 是欧拉函数.
